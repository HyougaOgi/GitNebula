# GitNebula の操作とデザイン

GitNebula はファイルマネージャーから使う Git クライアント。
基本の流れは **右クリック → GitNebula → 操作 → 確認・実行 → 閉じる**。
アプリを開いてからリポジトリや操作を選び直す必要をなくす。

macOS の差分画面はファイル一覧と、行番号付きの変更前・変更後の左右比較を表示する。追加・削除の色分け、行位置合わせ、縦スクロール同期、変更箇所への移動に対応する。履歴画面はコミットの GUI 一覧と詳細を上下に配置し、選択したコミットの変更ファイルを同じ左右比較で表示する。操作画面では対象リポジトリ・ブランチをコンパクトに示し、比較や一覧に画面の大部分を割り当てる。

## 右クリックメニュー

Finder、Explorer、Nautilus、Dolphin に以下の操作を提供する。

| 項目 | 開く画面 | 引き継ぐ対象 |
| --- | --- | --- |
| 変更をコミット | 対象ファイル・差分・メッセージ・コミット | 選択ファイル、または選択フォルダ以下の変更 |
| 差分を確認 | ファイル一覧・差分 | 選択ファイル、または選択フォルダ以下の変更 |
| 履歴を表示 | コミットグラフ | 対象のリポジトリ |
| 変更を受信（Pull） | 対象・リモート・実行・結果 | 現在のブランチと追跡先 |
| 変更を送信（Push） | 対象・リモート・実行・結果 | 現在のブランチと追跡先 |
| リモートを更新（Fetch） | 対象・リモート・実行・結果 | 対象のリポジトリ |
| ブランチを切り替え | 現在のブランチ・切り替え先・実行 | 対象のリポジトリ |
| リポジトリを複製（Clone） | 取得元・作成先・実行 | 選択した場所を作成先の親フォルダにする |
| 詳細操作 | ブランチ管理・変更・マージ | 対象のリポジトリ全体 |

- 背景の右クリックはそのフォルダを対象にする。以前のファイル選択を流用しない。
- Finder / Nautilus / Dolphin は複数選択を渡す。同じリポジトリ内のみ受け付ける。
- Explorer は単一のファイル・フォルダを対象にする。フォルダを選べば配下の変更をまとめて扱える。
- コミットでは対象の変更を最初から選択。全選択・選択解除と件数を表示する。
- リポジトリ・ブランチ・対象件数を常に明示。選択範囲外の変更をコミットに含めない。
- ファイルの状態は「変更」「新規」「削除」「名前変更」「競合」などの日本語で表示。
- メッセージが空、選択が空、リモートが未設定などの状態では実行できない。
- 送受信は対象を確認して実行する。起動するだけで push / pull は実行しない。
- 進行中と完了・失敗を表示する。完了後は結果を読んで閉じられる。
- 通常の画面にブランチ管理を並べない。競合の操作は競合またはマージ中にだけ表示。
- 直接アプリを起動した場合は小さな操作選択画面。「その他の操作」で画面を切り替えられる。
- 後続の右クリック操作は別ウィンドウ。入力中の下書きや処理を上書きしない。

## 起動契約

各 OS のエントリーポイントは `--action <操作> --path <絶対パス>` を受け付ける。
操作は `open`, `commit`, `diff`, `log`, `pull`, `push`, `fetch`, `switch`, `clone`, `workspace`。
macOS では追加で `init`, `stash`, `tags`, `remotes`, `tools` を受け付ける。機能とプラットフォームごとの対応は [FEATURES.md](FEATURES.md) を参照。
`--path` は複数指定可能。`--` 以後もパスとして扱う。旧 `--open <パス>` も利用可能。
Linux では従来の位置引数も利用可能。

Finder は `gitnebula://commit?path=…&path=…` のように操作をホスト名として渡す。
不正な操作名は拒否する。パスをシェル文字列に埋め込まない。
履歴と送受信はリポジトリ全体の操作で、ファイル選択によって履歴を絞り込む仕様ではない。

## 宇宙テーマ

| 要素 | 仕様 |
| --- | --- |
| 背景 | 深宇宙 `#090D1D`。紫と青の淡い星雲、静かな星の装飾 |
| パネル | 不透明な紺 `#12182C`。差分や入力欄の可読性を優先 |
| アクセント | 星雲の紫 `#B39DFF`。主要ボタン・ブランド |
| 主文字 | `#E9EAFA` |
| 補助文字 | `#A5B1CF` |
| エラー・競合 | `#FFBE90` と説明文。色だけで区別しない |
| 用語 | 標準的な Git 操作名と短い日本語の説明。宇宙の比喩を操作名にしない |

OS のファイル選択 UI、フォント、キーボード操作を使う。装飾にアニメーションは不要。
Mac は SwiftUI + Foundation Process、Linux は GTK 4 + Python subprocess、Windows は WPF + .NET Process。
GUI ランタイムは共有しない。

Pull は fast-forward のみ。追跡設定のあるリモートを初期選択し、追跡先のブランチ名を尊重する。
ブランチ削除はマージ済みのみ。削除とマージ中止は確認を求める。
リポジトリ内のテキストをマークアップとして解釈しない。

実装参照: [Finder Sync](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Finder.html)、[Explorer cascading menus](https://learn.microsoft.com/en-us/windows/win32/shell/creating-cascading-menu-handlers)、[Nautilus MenuProvider](https://gnome.pages.gitlab.gnome.org/nautilus-python/class-nautilus-python-menu-provider.html)。
