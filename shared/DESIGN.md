# GitNebula の共通デザイン

GUI の仕様を共有し、ランタイムや Git 呼び出しは OS ごとに実装する。

| 要素 | 仕様 |
| --- | --- |
| 背景 | 深宇宙 `#090D1D` |
| パネル | `#151B31` |
| アクセント | 星雲の紫 `#B39DFF` |
| 主文字 | `#E9EAFA` |
| 補助文字 | `#9CA8C7` |
| 画面 | 上部に名前・リポジトリ選択・更新、中央左に変更一覧、右に差分、下部にメッセージとコミット |
| 用語 | Git の標準用語を使う。宇宙の表現はタイトルや装飾に使う |

初期版はリポジトリ選択、更新、変更一覧、追跡済みファイルの差分、選択ファイルのコミットを提供する。
破壊的な操作は導入しない。パスとメッセージをシェル文字列に埋め込まず、引数として Git に渡す。
外部リポジトリ内のテキストは UI のテキストとして表示し、マークアップとして解釈しない。

Mac は SwiftUI + Foundation Process、Linux は GTK 4 + Python subprocess、Windows は WPF + .NET Process。
OS のファイル選択 UI、フォント、キーボード操作を使う。共通バイナリやクロスコンパイルは採用しない。
